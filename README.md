Buenas,
me llamo Jan
pero por internet prefiero que me llamen Aki.

Tengo 18 años y programo cuando debería estar estudiando (spoiler: siempre debería estar estudiando).
 No soy ningún genio de la programación, pero llevo un tiempo obsesionado con algo:

**La mayoría de programadores usa la IA como si fuera un buscador glorificado. Le piden código, les devuelve basura, no entienden por qué, y concluyen que "la IA no sirve para esto".**

El problema no es la IA. 
Es que no saben hablarle.

Yo aprendí a hablarle bien. 
Ahora construyo aplicaciones web con IA en el centro del proceso, y enseño a otros programadores a hacer lo mismo.

---

## ¿Qué hago exactamente?

Desarrollo web usando IA como herramienta principal, no como accesorio.

Nada de setups imposibles ni frameworks raros. VS Code, Claude Code, GitHub y Vercel. 
Con eso construyo, con eso enseño, y con eso va sobrado.

---

## Stack tecnológico

*O "lo que realmente uso, no lo que queda bien en el CV"*

**Frontend:**
- HTML / CSS / JavaScript (sin esto no hay nada)
- React (cuando el proyecto lo merece)

**IA & Herramientas:**
- Claude Code (el que más uso con diferencia)
- Claude en VS Code (para el día a día)
- Git (para no perder el trabajo cuando todo se rompe)

**Deploy:**
- Coolify auto-host (lo mejor que puedes hacer como programador)
- Vercel (rápido, gratis)
- GitHub (porque el código tiene que vivir en algún sitio)
